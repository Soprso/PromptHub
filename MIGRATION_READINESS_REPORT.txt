4. MIGRATION SCRIPTS
================================================================================

4.1 scripts/migrate-to-supabase.js (DESIGNED)
---------------------------------------------
✅ INCLUDED TABLES: image_of_day, prompts, likes, prompts_shared

✅ ID PRESERVATION: Uses upsert() which preserves existing IDs if they
   match the UUID format. New IDs generated via gen_random_uuid() if
   upsert fails.

✅ UPSERT SAFETY: supabase.from(table).upsert([insertData]) will update
   existing or insert new. Safe to rerun: duplicate records won't create
   issues due to UUID primary keys and unique constraints.

✅ FOREIGN KEY HANDLING: likes table has prompt_slug UUID REFERENCES
   prompts(slug) ON DELETE CASCADE. Migration preserves this relationship.

✅ TIMESTAMPS & DATA TYPES:
   - CockroachDB TIMESTAMP → Supabase TIMESTAMP WITH TIME ZONE
   - UUIDs mapped via gen_random_uuid()
   - TEXT arrays (tags) → Supabase TEXT[]

✅ FAILURE LOGGING: Each row migration logs errors to console.
   Script continues on individual row failures.
   Overall script exit code 1 on fatal errors.

✅ RERUNNABILITY: upsert makes it safe to rerun. No data deletion in
   the script. CockroachDB data preserved throughout.

❌ MISSING: Cloudflare R2 → Supabase Storage Image Migration Script
   Not yet created. Design see Section 4.2 below.

4.2 Cloudflare R2 → Supabase Storage Image Migration (DESIGN)
-------------------------------------------------------------
❌ NOT YET CREATED: Required functionality:

1. Read all image_url values from Supabase image_of_day table
   (after DB migration completes)

2. For each URL, parse the R2 filename from the URL
   (e.g., image-of-day-1234567890-abcd1234.png)

3. Download from Cloudflare R2:
   https://{accountId}.r2.cloudflarestorage.com/{filename}

4. Upload to Supabase Storage bucket image_of_day with same filename

5. Update the image_url field in the database record with new
   Supabase public URL

6. Log failures: original URL, filename, error message

7. Track: total migrated, total failed, total skipped

❌ Design Below (Do Not Execute):
```
pseudocode - not to be executed:

const r2Images = await supabase.from('image_of_day').select('image_url');
const r2 = createR2Client({/* credentials */);

for (const img of r2Images.data) {
  const filename = parseR2Filename(img.image_url);
  try {
    const r2File = await r2.files.get(filename);
    const supaResult = await supabase.storage
      .from('image_of_day')
      .upload(filename, r2File);
    const publicUrl = supabase.storage.from('image_of_day').getPublicUrl(filename);
    await supabase
      .from('image_of_day')
      .update({ image_url: publicUrl })
      .eq('id', img.id);
    console.log(`Migrated ${filename}`);
  } catch (err) {
    console.error(`Failed ${filename}: ${err.message}`);
  }
}
```
